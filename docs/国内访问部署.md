# 国内访问部署

这份作品集已导出为静态网站，不需要数据库或自行维护服务器。代码保存在 GitHub；面试官访问的是部署后的域名，不需要访问 GitHub。

## 使用 GitHub 自动部署

现有 `zengactivity` 项目已通过 GitHub 连接此仓库，生产分支为 `main`。项目设置 → Build Deployment Configuration 应使用：

| 配置 | 值 |
| --- | --- |
| Preset framework | `Other` |
| Root directory | `./` |
| Build output directory | `dist/client` |
| Compile commands | `npm run build` |
| Install command | `npm ci` |

仓库根目录的 `edgeone.json` 固定安装命令、构建命令、输出目录和活动详情页路由。这里使用 Vinext 静态导出，不能选择 `Next` 或 `Next SSG`：这些预设会寻找 `out` 或 `.next/required-server-files.json`，而实际静态文件在 `dist/client`。框架预设需要在控制台选择。

推送 `main` 后可在 Build & Deploy 查看部署状态。构建成功只表示文件已生成，还需等待部署成功，再通过已绑定的域名或有效预览链接访问。

## 直接上传方式

对于没有云账号和域名、希望尽快用于面试的情况，使用腾讯云 EdgeOne Pages 静态托管（部分最新文档称为 Makers）和自购域名。

1. 注册腾讯云账号，按平台要求完成实名认证。
2. 注册一个简短、易读的域名，购买前同时查看首年和续费价格。现有域名也可使用。
3. 在 EdgeOne Pages 创建项目，选择“直接上传”和“全球可用区（不含中国大陆）”。
4. 上传准备好的 `活动作品集_EdgeOne上传包.zip`。压缩包内的 `index.html` 已位于根目录，且包含活动详情页的访问规则。
5. 在项目的域名管理中添加自己的域名，按控制台提示添加验证记录和 CNAME 记录，启用 HTTPS。
6. 域名和证书生效后，用国内手机流量和 Wi-Fi 分别打开首页、活动详情、图片及简历下载；检查完成后再把域名发给面试官。

这个区域选择不要求 ICP 备案，但网站仍经过境外节点，国内速度与连通性需要实际测试，不能承诺所有地区和运营商均稳定。若之后希望使用内地节点，再准备符合备案要求的云资源及域名，完成 ICP 备案后选择“中国大陆可用区”。

不要将平台默认项目域名作为面试材料中的正式链接。当前 Makers 官方规则说明：默认项目域名在中国大陆访问需要使用有效预览链接，预览链接有效期为 3 小时。正式使用请绑定自己的域名。

Pages 提供免费用量套餐，域名单独购买；配额和是否产生费用以开通时控制台展示为准。

## 后续更新

现有 Git 集成项目会随 `main` 的推送自动部署。直接上传的项目不会随 GitHub 提交自动更新。以后修改网站时，重新构建并上传新的 ZIP。若需要自动发布，可以另建通过 Git 仓库集成的项目；当前官方说明直接上传项目不能直接切换到 Git 集成。

```bash
npm ci
npm run build
python3 scripts/package_edgeone.py outputs/活动作品集_EdgeOne上传包.zip
```

打包脚本只收录 `dist/client/` 构建产物，并生成 EdgeOne 的静态路由规则。端午和 23 楼活动不包含在上传包中。原图与完整 WebP 存档保留在本地。
